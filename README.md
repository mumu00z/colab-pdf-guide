# Colab to PDF Guide

A step-by-step student guide to exporting completed Google Colab notebooks as PDFs.

## Contents

- `index.html`: tutorial text and copyable Python code
- `style.css`: responsive page styling
- `app.js`: copy buttons and navigation highlighting
- `.nojekyll`: serve these static files without Jekyll processing

## Preview and edit

Keep the three web files in one folder. Open `index.html` in a browser to preview.
Edit it in a plain-text or code editor to change the instructions and code.

## Publish with GitHub Pages

1. Create a public repository named `colab-pdf-guide`.
2. Upload the files in this folder to the repository root, not the ZIP itself.
3. In Settings > Pages, select Deploy from a branch.
4. Select main and /(root), then save.
5. Use the published URL shown in the Pages settings.

The final URL uses your GitHub username and repository name.
