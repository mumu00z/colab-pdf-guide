01

Finish and save your assignment

Open your original assignment notebook in Google Colab. Answer every required question and complete every exercise.

  1. Click Runtime → Run all and wait for every cell to finish.
  2. Check that the required answers, tables, and figures are visible. Resolve any red errors.
  3. Click File → Save, or press Ctrl + S on Windows / Command + S on Mac. Wait for saving to finish.
Outputs must be saved in the notebook.The converter uses the code and outputs already stored in your .ipynb. It does not run your assignment. If “Omit code cell output when saving” is enabled in Colab’s notebook settings, turn it off and save again.
02

Download the latest .ipynb

In your assignment notebook, select:

File → Download → Download .ipynb

Your browser will download a file such as Lab4_EDA_Text_Reviews.ipynb. Remember its location—usually your computer’s Downloads folder.

Use the version you just saved.Downloading an older notebook can produce a PDF with missing answers or outputs.

from google.colab import files
from pathlib import Path

uploaded = files.upload()
notebook_paths = []

for name, data in uploaded.items():
    if Path(name).suffix.lower() == ".ipynb":

        path.write_bytes(data)

        print(f"Ready: {path.name}")

if not notebook_paths:
    raise ValueError("No .ipynb uploaded. Run this cell again and select your notebook.")

Conversion notebook · Cell 3

Add the PDF converter

Paste the entire block into a new code cell and run it. This defines the converter; it does not create a PDF yet.

Cell 3 · Define converter
from nbconvert import HTMLExporter
from playwright.async_api import async_playwright

PDF_STYLE = """
@page { size: Letter portrait; margin: 0.5in; }
html, body { height: auto !important; overflow: visible !important; }
.jp-Notebook { width: 100% !important; padding: 0 !important; }
.jp-Cell, .jp-InputArea, .jp-OutputArea,
.jp-OutputArea-child, .jp-OutputArea-output {
    min-width: 0 !important;
    max-width: 100% !important;
    max-height: none !important;
    overflow: visible !important;
}
pre, .highlight pre, .jp-RenderedText pre {
    white-space: pre-wrap !important;
    overflow-wrap: anywhere !important;
    word-break: break-word !important;
    max-height: none !important;
    overflow: visible !important;
}
table { width: 100% !important; table-layout: fixed !important; }
th, td { white-space: normal !important; overflow-wrap: anywhere !important; }
img, svg { max-width: 100% !important; height: auto !important; }
.jp-InputPrompt, .jp-OutputPrompt { min-width: 0 !important; }
"""

async def convert_notebook(ipynb_path, output_dir):
    exporter = HTMLExporter(template_name="lab")
    exporter.embed_images = True
    html, _ = exporter.from_filename(str(ipynb_path))
    pdf_path = output_dir / f"{ipynb_path.stem}.pdf"

    async with async_playwright() as p:
        browser = await p.chromium.launch(args=["--no-sandbox"])
        try:
            page = await browser.new_page()
            await page.set_content(html, wait_until="load", timeout=120000)
            await page.add_style_tag(content=PDF_STYLE)
            await page.emulate_media(media="print")
            await page.evaluate("document.fonts.ready")
            await page.evaluate("""async () => {
                await Promise.all(Array.from(document.images).map(img =>
                    img.complete ? Promise.resolve() : new Promise(resolve => {
                        img.onload = resolve;
                        img.onerror = resolve;
                    })
                ));
                if (window.MathJax && window.MathJax.typesetPromise) {
                    await window.MathJax.typesetPromise();
                }
            }""")
            await page.pdf(
                path=str(pdf_path),
                format="Letter",
                print_background=True,
                prefer_css_page_size=True
            )
        finally:
            await browser.close()

    return pdf_path
No printed output is expected.When the cell finishes without a red error, continue to the next step. This version uses Colab-compatible asynchronous browser controls and wraps long code and text output.

Conversion notebook · Cell 4

Create your PDF

Paste this into a new code cell and run it. Wait for the conversion to finish.

Cell 4 · Convert to PDF
output_dir = Path("/content/PDFs")
output_dir.mkdir(exist_ok=True)
converted_files = []

for notebook_path in notebook_paths:
    print(f"Converting: {notebook_path.name}")
    try:
        pdf_path = await convert_notebook(notebook_path, output_dir)
        converted_files.append(pdf_path)
        print(f"Saved: {pdf_path}")
        print()
    except Exception as error:
        print(f"FAILED: {notebook_path.name}")
        print(error)
        print()

if not converted_files:
    raise RuntimeError("No PDF created. Check the error above and the troubleshooting section.")

print(f"Done: {len(converted_files)} PDF(s). Continue to Cell 5.")

Conversion notebook · Cell 5

Find and download the PDF

The PDF is now in Colab’s runtime storage. Download it to your computer using either method below.

Option A · Run the download cell

Paste this into your fifth code cell and run it. It uses your actual filename, so you do not need to edit the code.

Cell 5 · Download PDF
from google.colab import files
import zipfile

if not converted_files:
    raise RuntimeError("Run Cell 4 successfully before downloading.")

if len(converted_files) == 1:
    print(f"Downloading: {converted_files[0].name}")
    files.download(str(converted_files[0]))
else:
    zip_path = Path("/content/PDFs.zip")
    with zipfile.ZipFile(zip_path, "w", zipfile.ZIP_DEFLATED) as archive:
        for pdf_path in converted_files:
            archive.write(pdf_path, arcname=pdf_path.name)
    print("Downloading PDFs.zip. Extract it to see your PDFs.")
    files.download(str(zip_path))

For one notebook, your browser downloads the PDF. For multiple notebooks, it downloads PDFs.zip; extract the ZIP on your computer.

09

Check every page, then submit

Open the downloaded PDF on your computer. Check it from the first page to the last page before submitting.

Conversion success is not a completeness check.The converter cannot recover outputs omitted from the .ipynb, rows already shortened to “…” in a displayed table, or unsaved work. Interactive charts and external images may need a static version in your assignment.

If anything is missing, return to the original assignment, fix it, run the relevant cells, save, and download a fresh .ipynb. Then repeat Cells 2, 4, and 5 in the converter. Submit to Canvas according to your instructor’s requirements.

If something goes wrong

Chromium is missing, or its executable cannot be found

Run the following in a new cell, then rerun Cell 4. If installation fails, check the last red error and rerun Cell 1.

Fix · Install Chromium
import sys
import subprocess

subprocess.run(
    [sys.executable, "-m", "playwright", "install",
     "--with-deps", "chromium"],
    check=True
)
“NameError” or a variable is not defined

Run the cells in order. Cell 2 creates notebook_paths; Cell 3 defines convert_notebook; Cell 4 creates converted_files. After a runtime reset, run Cells 1–5 again and upload the notebook again.

“Playwright Sync API inside the asyncio loop”

Use the complete Cell 3 code in this guide. It uses async_playwright. Then rerun Cell 4, including the await keyword. Do not mix it with an older synchronous browser test.

The PDF folder is empty, or the download does not start

Check Cell 4 for a Saved: message and run the optional file check in Step 8. If the PDF exists, use Files → PDFs → ⋮ → Download. Check your browser’s downloads list and allow the download if prompted.

Code, tables, or figures are missing or too wide

Inspect the original notebook and the newly downloaded .ipynb. Save outputs and re-export. For a very wide table, show fewer columns at a time or split it into several tables before saving. Expand truncated output and replace interactive figures with static images when necessary. Check the new PDF again.

The installation fails or the runtime disconnects

Read the final error in Cell 1. Reconnect, then rerun installation. If packages still fail to load after installation, use Runtime → Restart session, then run Cells 1–5 in order. If the runtime was reset or deleted, upload your assignment again.
